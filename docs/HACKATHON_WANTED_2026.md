## 2. GO/NO-GO 판정

### 결론: **GO (조건부)**

리포닥은 이미 "실측 완료된 작동하는 제품" 상태이므로, 이 대회의 핵심 관문인 "실제로 작동하는 서비스 링크"를 **배포만으로** 충족할 수 있습니다. 추가 개발이 아니라 배포·문서화·홍보 자산 작업이 전부이며, 무료 참가 + 뱃지 + 상금 구조라 기회비용이 낮습니다. 단, 아래 3가지 조건을 전제로 합니다.

### GO 근거

| # | 근거 | 근거 설명 |
|---|---|---|
| 1 | **제품이 이미 실측 완료 상태** | 스캔 파이프라인 3리포 ≤ 90초, LLM 해설 채움률 100%, 웹 3화면 Lighthouse 96 실측값 확보. "작동하는 서비스" 요건을 배포만으로 충족 |
| 2 | **AI 활용이 제품의 핵심** | LLM 해설 + 인용 검증 + 수치 필터 + 토글 증명. 심사 기준 중 "AI 활용 적절성"을 정면으로 찌르는 구조 |
| 3 | **일정이 양립 가능** | 원티드 제출 9/20 vs SCNU 제출 9/27. 배포를 9/20 전으로 앞당기면 **양쪽 대회 모두 참전 가능** |
| 4 | **기회비용 낮음** | 무료 참가 + 제출자 전원 AI Builder 뱃지 + 상금 구조. 불참 시 얻을 것 대비 잃을 것이 큼 |

### 차별점 — "AI를 어떻게 신뢰 가능하게 썼나"의 증명

- "AI가 코드는 짜주지만 한국 법적 책임은 아무도 알려주지 않는다"는 문제 의식
- 코드 신호 → 조문 링크 **역추적**이라는 미확인 아이디어(도전 과제로 어필 가능)
- 탐지/해설 **분리**로 AI 환각을 구조적으로 차단 — 정적분석 결과(사실)와 LLM 해설(해석)을 분리하고 토글로 증명
- AI 해커톤 심사에서 "환각을 막는 구조를 만든 사례"로 어필 가능

| # | 리스크 | 내용 | 대응 |
